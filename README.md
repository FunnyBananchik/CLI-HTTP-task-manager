# Task Manager (Go + SQLite + REST API)

Учебный проект, представляющий собой полноценный backend-сервис для управления задачами (To-Do List). 
Проект включает в себя HTTP-сервер, работающий по принципам REST API, слой работы с базой данных SQLite и CLI-интерфейс для взаимодействия с сервером.

## Технологический стек

*   **Язык:** Go (Golang)
*   **Веб-сервер:** Стандартная библиотека `net/http` (без сторонних фреймворков)
*   **База данных:** SQLite (драйвер `modernc.org/sqlite`)
*   **Формат данных:** JSON
*   **Логирование:** Стандартная библиотека `log` с записью в файл (`app.log`)

## Как запустить

### Предварительные требования
Убедитесь, что у вас установлен [Go](https://go.dev/dl/) (версия 1.20 или выше).

### Установка и запуск
1. Клонирование репозитория:
   ```bash
   git clone https://github.com/FunnyBananchik/CLI-HTTP-task-manager.git
   cd CLI-HTTP-task-manager
   ```
2. Запуск сервера:
   ```bash
   go run main.go server
   ```
   *Сервер запустится на `http://localhost:8080`. Файл базы данных `tasks.db` и лог-файл `app.log` создадутся автоматически при первом запуске.*

## Работа с API

Сервис поддерживает следующие эндпоинты:

| Метод | Эндпоинт | Описание | Тело запроса (JSON) | Ответ |
| :--- | :--- | :--- | :--- | :--- |
| `GET` | `/tasks` | Получить список всех задач | — | `200 OK` + массив задач |
| `POST` | `/tasks` | Создать новую задачу | `{"title": "Текст"}` | `201 Created` + задача |
| `GET` | `/tasks/{id}` | Получить задачу по ID | — | `200 OK` + задача |
| `PUT` | `/tasks/{id}` | Отметить задачу выполненной | — | `200 OK` + задача |
| `DELETE` | `/tasks/{id}` | Удалить задачу по ID | — | `204 No Content` |

**Пример ответа с задачей:**
```json
{
  "id": 1,
  "title": "Купить хлеб",
  "done": false,
  "created_at": "2024-05-20T14:30:00Z"
}
```

## Использование CLI

Помимо API, проект имеет встроенный CLI-интерфейс для быстрого управления задачами прямо из терминала.

> **Важно:** Сервер должен быть запущен в отдельном окне терминала.

*   **Добавить задачу:**
    ```bash
    go run main.go add "Сделать домашку"
    ```
*   **Показать все задачи:**
    ```bash
    go run main.go list
    ```
*   **Показать задачу по ID:**
    ```bash
    go run main.go get 1
    ```
*   **Отметить как выполненную:**
    ```bash
    go run main.go done 1
    ```
*   **Удалить задачу:**
    ```bash
    go run main.go delete 1
    ```
